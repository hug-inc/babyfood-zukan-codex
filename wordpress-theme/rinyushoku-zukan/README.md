# 離乳食ずかん WordPressテーマ

GitHub Pages版「離乳食ずかん」のデザインを、WordPressのクラシックテーマとして再構築した専用テーマです。

## インストール

1. `rinyushoku-zukan.zip` を WordPress 管理画面の「外観 → テーマ → 新規追加 → テーマのアップロード」からアップロードします。
2. 「離乳食ずかん」を有効化します。
3. 「設定 → 表示設定」でホームページの表示を確認します。固定ページを指定しても、サイトトップでは `front-page.php` が使われます。
4. 必要に応じて「外観 → メニュー」でメイン・フッターメニューを割り当てます。未設定でも既定メニューが表示されます。

FileZillaでは、このフォルダーを次の場所へそのままアップロードできます。

```text
/home/tomatorat2/www/babyfood-zukan/wp-content/themes/rinyushoku-zukan/
```

## コンテンツ管理

- 「ショップ」投稿タイプ：ショップ名、紹介文、アイキャッチ画像、ショップURL、注目枠への表示設定
- ショップ編集画面の「対象月齢」「種類」「食材」で、表示したいカテゴリーを複数選択
- トップページの「新着」はショップの公開日順で自動表示
- 公式ショップへのクリック数は、同じブラウザーから同じショップへの連続操作を1日1回にまとめて集計
- ショップ一覧とショップ編集画面でクリック数を確認可能
- 「ベビーフード」投稿タイプ：商品名、本文、抜粋、アイキャッチ画像
- 商品分類：対象月齢、商品タイプ、食材、保存方法、ブランド
- 商品情報メタボックス：価格、公式EC URL、原材料、アレルゲン、栄養成分、PR、デモデータ、閲覧数
- 標準の「投稿」：お役立ち記事
- 標準の「固定ページ」：運営会社、お問い合わせ、利用規約など

ショップが未登録の間は、トップページにTEDEMOGUの初期ブランドカードが表示されます。ショップを登録すると、WordPressのショップデータから各ブランド枠が自動生成されます。実在メーカーの商品情報は推測で登録しないでください。

## 推奨固定ページ

以下のスラッグで固定ページを作成すると、既定ナビゲーションのリンク先として利用できます。

- `company`：運営会社
- `contact`：お問い合わせ
- `terms`：利用規約
- `privacy`：プライバシーポリシー
- `for-makers`：メーカーの方へ
- `compare`：商品比較（将来実装用）
- `blog`：お役立ち記事一覧

## 開発上の注意

- 現時点ではテーマ単体で動作するよう、商品投稿タイプと分類をテーマ内に実装しています。
- 将来テーマを頻繁に変更する運用になった場合、`inc/content-types.php` は専用プラグインへ移動してください。
- 本番投入前に、ステージング環境でパーマリンクを一度保存し、商品アーカイブ `/products/` が表示されることを確認してください。
- お問い合わせ送信、メーカー認証、販売成果計測、サーバー側の商品比較は今後のバックエンド実装範囲です。
